## Q1 - Log File Parsing (Java)

A program that reads and filters log files based on:
- Log types: error, warning, info, debug
- Number of lines (default: 10)
- Most recent logs (from end of file)

Default log type: **error**  
Supports exception handling for invalid input

## Q2 - Inventory Filtering (C++)

A program that filters inventory data from a JSON file based on:
- Maximum CPU usage
- Maximum Memory usage
- Operating System type (Linux/Windows)

Handles large datasets  
Validates filter criteria  
Uses object-oriented design

## Q3 - Hardware Information System (Python)

A system that displays real-time hardware information using OOP and OS commands.

Features:
- Detects OS (Windows/Linux)
- Retrieves CPU, Memory, Disk, IP, Hostname
- Displays output in JSON format

Uses abstraction, inheritance, polymorphism  
Uses system-level commands and subprocess module
